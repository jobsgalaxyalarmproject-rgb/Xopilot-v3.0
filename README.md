ABOUT
-----
Xopilot is a Windows-based assistant designed to help users
perform tasks, access system information, launch applications,
and provide a foundation for future AI-powered features.

FEATURES
--------
- Interactive command menu
- Launch Notepad
- Launch Calculator
- Open web browser
- View system information
- Display date and time
- Expandable AI chatbot framework

REQUIREMENTS
------------
- Windows 10 or Windows 11
- Command Prompt (CMD)

INSTALLATION
------------
1. Download the Xopilot package.
2. Extract the ZIP file.
3. Double-click Xopilot.bat.

USAGE
-----
1. Run Xopilot.bat.
2. Select an option from the menu.
3. Follow the on-screen instructions.
